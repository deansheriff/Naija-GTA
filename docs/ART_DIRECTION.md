# Illustrated neighborhood — asset manifest

The new street uses a fixed elevated camera, painterly scenery, small expressive sprite characters and painted environmental shading. It adapts the illustrated 2D direction discussed using The Omins as a visual reference to contemporary Nigerian street life. No assets from that game were downloaded or incorporated. The background is a single painted first-street asset; modular buildings/interiors and independently animated foliage remain later work.

All four PNG assets were created with the **built-in OpenAI imagegen tool**, copied into `game/assets/`, and integrated in `world/neighborhood_2d.gd`. Alpha is retained for the character/vehicle sheets. The scene uses sprite frames and AtlasTexture regions directly; no external image editing or paid API key was required. The protagonist has eight directional walk frames, with two frames per direction. Amaka/Yemi and the crew have static sprite poses with optional gentle ambient movement. Pedestrians reuse the directional protagonist sheet with color variations.

## Current rendering limits

Home customization changes a visible banner/accent; it does not repaint the baked background. Low/Medium/High adjust traffic/pedestrian count, idle sway and contact shadows; frame caps remain 30/60. Named interaction characters are available on every tier. All tiers currently share the same painted asset resolution. View distance caps pedestrians; Ambient animation can pause the street. Foreground polygons reuse the painting's pixels for approximate tree/bus-shelter occlusion, not full layered scenery or world collision. Android HD downloads and a larger modular art library are not implemented.
