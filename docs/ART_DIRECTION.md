# Illustrated neighborhood — asset manifest

The street uses a fixed elevated camera, painterly scenery, small expressive sprite characters and painted environmental shading. It adapts the illustrated 2D direction discussed using The Omins as a visual reference to contemporary Nigerian street life. No assets from that game were downloaded or incorporated. Version 0.5 replaces the former single-background world with independent painted shells/roofs/trunks/canopies and code-native ground, road, pavement and furniture. The original first-street painting remains an archived art reference and is excluded from the game exports.

All game PNGs were created with the **built-in OpenAI imagegen tool**, copied into `game/assets/`, and integrated in `world/neighborhood_2d.gd`. Alpha is retained for the character/vehicle/wildlife sheets. The scene uses AtlasTexture regions; no external image editing or paid API key was required. Version 0.4 supersedes the legacy eight-frame walk sheet: its nearly repeated leg poses and one incorrectly facing side frame were caught in player review. New protagonist walk/idle sheets, distinct pedestrians, wildlife and grounded traffic are described below. Amaka/Yemi and the crew retain static sprite poses.

## Current rendering limits

Home customization changes a banner/accent, not all building-wall textures. Quality changes crowd/wildlife density, soft shadows and foliage effects; frame caps remain 30/60. Tire contact remains visible on Low. Named interaction characters remain available at every tier. All tiers share asset resolution. Version 0.5 uses separate tree canopies for wind, real solid footprints for player movement, front-wall sprite parts for room occlusion and separate fading roofs. The ground/furniture rendering is simpler than the painted modules; additional painted props and richer surface detail can improve this authored kit without restoring a single-background world. Seeded districts, driveable travel and Android HD packs remain future work.
