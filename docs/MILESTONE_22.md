## Playable comparison and recovery

The board saves interpretations of SR-18's 21:14 time, Nneka's attributed account and PB-1's issue label. Incorrect/incomplete checks retain selections and allow free correction. Guided matching fills source labels but still requires a check. Readiness, attempts (bounded to 100,000) and chosen interpretations are server-owned; a ready board ignores further changes. The illustrated desk's selected-claim dots and existing controls update in place. Journal navigation blocks board input. Pause/reload, save-code recovery, server restart and exact retries retain the board.

`campaign_compare` validates the current board stage and listed input inside the ordinary revision/receipt transaction. Clients cannot send readiness, evidence or permission objects. Required source checks block missing records with an earned-only restoration route. Completion grants only this chapter's eligible records; it does not silently repair missing unrelated earlier sources.
